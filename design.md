# Структуры данных и алгоритмы

`GameState` — типизированный объект (record) с полями `settings`, `secret`, `history`, `status`, `startedAt`.
Это **центральная структура** модуля: она описывает полное состояние одного раунда и используется как тип _входа_ и _выхода_ во всех функциях — `startNewGame` создаёт её, `addAttempt` и `updateSettings` возвращают её новую версию, `getElapsedSeconds` читает из неё.

`GameState` — обычный объект, а не набор переменных и не класс: его поля меняются вместе, поэтому он передаётся как единое целое и обновляется иммутабельно через `spread`, а логика вынесена в отдельные чистые функции — так состояние легко скопировать как обычные данные и тестировать.

**Секрет и догадки — строки, а не числа.** Строка сохраняет ведущие нули ("0123" ≠ "123") и позволяет одним кодом работать с системами счисления BIN, OCT, DEC и HEX.

История попыток — Attempt[], упорядоченный массив. Массив выбран потому, что важен порядок попыток (для отображения и анализа), и новые записи добавляются в конец. Добавление выполняется через [...history, entry], что создаёт новый массив и сохраняет предыдущее состояние неизменным. Альтернативы (Set, Map) не подходят: Set теряет порядок и не хранит подсказки, Map избыточен, так как ключ не нужен.

Алгоритм `evaluateGuess`. Двухпроходный подсчёт быков и коров. Первый проход: символы, стоящие на своих местах — это быки. Второй проход: оставшиеся символы догадки, которые есть в секрете на других позициях — это коровы. Сложность O(n) по времени, где n — длина секрета.

Алгоритм `countPossibleSecrets`. Перебор всех допустимых секретов (base^length вариантов) с фильтрацией: остаются только те, которые для каждой попытки из истории дают ровно те же быки и коровы. Каждая попытка — это ограничение на секрет, поэтому кандидат возможен, только если проходит все ограничения. Сложность O(base^length · |history| · length), что приемлемо для типичных настроек (длина 4–6, основание ≤ 16).

## Генерация секрета - GenerateSecret.ts

Это выборка с повторами. Строим алфавит — O(base). Потом случайно тянем цифры, пока не наберём length уникальных. Повторы отбрасываются через Set. В среднем это O(length) итераций, но строгой верхней границы нет: теоретически можно долго попадать в уже собранные цифры. Память — O(base + length).

## Валидация попытки - isValueGuess.ts

`createDigitValidator` — фабрика: проверяет основание, строит множество допустимых цифр и возвращает функцию „это допустимая цифра?". isValidGuess применяет её каскадом: сначала тип и длина, потом every по каждому символу, потом проверка уникальности через Set. Сложность isValidGuess — O(base + n), где валидатор даёт O(base), а проверки символов и уникальности — O(n). Сам предикат — O(1) на символ.

## Подсчёт быков и коров - evaluateGuess.ts

`evaluateGuess` сначала считает быков — совпадения на своих позициях. Потом убирает эти позиции, строит карту частот остатка секрета и считает коровы, уменьшая счётчик при каждом использовании, чтобы не засчитать одно вхождение дважды. Сложность — O(n) по времени и памяти.

## Количество возможных секретов - countPossibleSecrets.ts

Считает число размещений A(base, length) — сколько секретов без повторов можно составить. Рекурсия: base · compute(length−1, base−1), база — length = 0 даёт 1. Результаты кешируются в Map по ключу length:base, поэтому повторные вызовы — O(1). Сложность первого вызова — O(length) по времени и памяти.

## Лидерборд и хранение

`Leaderboard` — UI-компонент-фабрика. Состояние (активная система счисления, ссылки на кнопки вкладок) хранится в замыкании, наружу отдаётся интерфейс {root, open, close} — инкапсуляция без классов. Список записей — массив ScoreEntry[] из getTop(base, 10), порядок в массиве соответствует месту в рейтинге. Рендер собирает строки в DocumentFragment и вставляет одной операцией replaceChildren — это минимизирует reflow и избегает innerHTML (защита от XSS). Переключение вкладок — снятие активного класса со всех кнопок и установка на нажатую. Сложность рендера — O(k) при фиксированном k = 10, то есть фактически константа.

# Сложность алгоритмов

Обозначения: `n` — длина секрета (`length`), `base` — основание системы счисления (2, 8, 10, 16). `base` входит в сложность как размер алфавита, а не как число шагов: в `evaluateGuess` и `countPossibleSecrets` число шагов зависит от `length`, а `base` — множитель или размер таблицы.

| Функция                  | Время                                          | Память           | Ключевая идея                          |
| ------------------------ | ---------------------------------------------- | ---------------- | -------------------------------------- |
| `generateSecret`         | **O(base + length)** в среднем                 | O(base + length) | выборка с повторами, `Set`             |
| `isValidGuess`           | **O(base + n)**                                | O(base + n)      | каскад проверок, `every`, `Set`        |
| `evaluateGuess`          | **O(n)**                                       | O(n)             | две фазы + карта частот                |
| `countPossibleSecrets`   | **O(length)** первый вызов, **O(1)** повторный | O(length)        | размещения + мемоизация                |
| Leaderboard `renderList` | **O(k)**, `k = 10` → фактически O(1)           | O(k)             | `DocumentFragment` + `replaceChildren` |

# Clean code

## Принципы чистого кода

| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Единственная ответственность (SRP)**            | `evaluateGuess.ts`, `isValidGuess.ts`, `createDigitValidator.ts`                                                                                                                                            | Каждая функция делает одно: `evaluateGuess` только считает быков и коров, `isValidGuess` только проверяет догадку, `createDigitValidator` только готовит предикат. Логика подсчёта не смешана с валидацией. |
| **Маленькие функции**                             | `createDigitValidator` → предикат; `isValidGuess`                                                                                                                                                           | Валидатор возвращает короткую функцию `(char) => …`; `isValidGuess` — каскад из 4 коротких проверок, каждая в одну строку.                                                                                  |
| **Ясные имена**                                   | `startNewGame`, `addAttempt`, `updateSettings`, `getElapsedSeconds`                                                                                                                                         | Имя = действие + объект. `generateSecret`, `countPossibleSecrets` читаются как вопрос: «сгенерируй секрет», «посчитай возможные секреты». Нет `doStuff`, `data`, `tmp`.                                     |
| **Отсутствие побочных эффектов (чистые функции)** | `game.type.ts`: `startNewGame`, `addAttempt`, `updateSettings`, `getElapsedSeconds`; `evaluateGuess`; `isValidGuess`; `createDigitValidator`                                                                | Ни одна не мутирует вход: обновление через `{ ...state }` и `[...history, entry]`. `addAttempt` возвращает новый `GameState`, старый остаётся валидным.                                                     |
| **Иммутабельность**                               | `addAttempt`, `updateSettings`, `startNewGame`                                                                                                                                                              | Новое состояние создаётся spread-оператором, а не присваиванием в поля. Отклонённая попытка возвращает **тот же** объект (`return state`).                                                                  |
| **Ранний выход (guard clauses)**                  | `addAttempt` (`if (state.status !== 'playing') return state`); `isValidGuess` (4 ранних `return false`); `countPossibleSecrets` (проверки аргументов); `createDigitValidator` (`throw` при неверном `base`) | Вложенности `if/else` нет — каждая проверка отсекает свой случай и выходит. Читается сверху вниз.                                                                                                           |
| **DRY (не повторяйся)**                           | `createDigitValidator`                                                                                                                                                                                      | Построение алфавита и проверка символа вынесены в одну фабрику, которую использует `isValidGuess`. Нет дублирования `toString(base)` в двух местах.                                                         |
| **Одна точка изменения**                          | `SYSTEMS` в `leaderboard.ts`                                                                                                                                                                                | Список систем счисления — одна константа. Чтобы добавить систему, правится одно место, а не несколько `if`.                                                                                                 |

Никто снаружи не трогает внутренние переменные.                                                         |
| **Явные зависимости (Dependency Injection)**      | `generateSecret(length, base, random = Math.random)`                                                                                                                                                        | Источник случайности передаётся параметром. В тестах можно подставить детерминированный, в приложении — `Math.random`. Функция не привязана к глобальному источнику.                                        |
