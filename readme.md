## Bulls&Cows

Bulls and Cows is a secret number guessing game played with unique digits. The computer guesses a number of a given length in a given numeral system, the player enters guesses, and after each attempt receives a hint: how many digits are guessed and in their correct position (bulls), and how many are guessed but in the wrong position (cows). The game continues until the player guesses the number — there is no attempt limit, but the number of attempts and time affect the leaderboard result.

This assignment is not about the interface, but about architecture. All game logic must be written in a functional style: pure functions without side effects, immutable data structures, higher-order functions, currying, memoization, and recursion — not as abstract exercises, but as a natural way to solve the specific tasks of this game.
